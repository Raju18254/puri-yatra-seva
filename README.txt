PURI YATRA SEVA — WEB APP PACKAGE

Files:
- index.html: website and WhatsApp enquiry form
- manifest.json: installable web app metadata
- sw.js: basic offline caching
- icon-192.png / icon-512.png: app icons

Important:
1. The WhatsApp destination is set to 917978155503.
2. This is a Progressive Web App (PWA) starter package, not yet published online and not an APK.
3. To install the app-like version, publish the files on an HTTPS host. Service worker and install prompts do not work reliably from a local file.
4. For a simple public website, upload all files to a static host such as GitHub Pages. See https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
5. To list an Android app in Google Play, additional Android packaging, Play Console setup, policy declarations, and review are required.
